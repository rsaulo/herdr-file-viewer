# Try tsk: one board for you and your agents

**tsk** is a terminal task board built for working alongside your agents. Capture and organize work in the TUI, while your agents read and update the same tasks through the CLI.

Use it standalone with `tsk`, or add it to Herdr and open the board anytime with **prefix+t**.

Install it:  curl -fsSL https://gettsk.sh/install.sh | sh

Then, for Herdr: tsk setup herdr

Learn more at **gettsk.sh**.
